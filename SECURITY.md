# Security Policy

## Supported version

Security fixes are provided for the latest `1.x` release of Telemt Installer.

## Reporting a vulnerability

Please do not publish secrets, server addresses, proxy links, configuration files, logs containing IP addresses, or proof-of-concept attacks in a public issue.

Open a private security advisory in the GitHub repository:

<https://github.com/ander1k/telemt/security/advisories/new>

Include the affected installer version, operating system, expected behavior, actual behavior, and a minimal reproduction with all secrets removed.
